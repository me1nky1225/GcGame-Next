## 2. GitHub Release 说明（v0.1.0）

```markdown
## GCM Next v0.1.0

单机游戏修改器的桌面管理器。第一版把「找 → 下 → 装 → 启动」这条链路做通了。

### 新增
- **我的修改器**：扫描本地目录，卡片列表带 Steam 封面、中英双标题、来源徽章、版本、使用次数
- **发现**：四源合库 3187 条（FLiNG 712 / the-cheat-script 2141 / 小幸 61 / 本地旧库 273），分源缓存、可单独开关
- **下载队列**：解析下载页 → 带 Referer 直链 → 断点续传 → zip/7z/rar 解压 → 自动入库，支持暂停/继续/重试
- **中文搜索**：后台查 Steam 补中文名，搜「黑神话」「影之刃零」可直接命中，也支持拼音首字母
- **主题与语言热切换**：深/浅色、简/繁/英，改完即刻生效，不用重启
- **面板可收起**：左右两侧都能收，列表铺满整宽（Ctrl+B / Ctrl+D）
- 随包内置 7-Zip，用户机器不用另装

### 说明
- 只支持 Windows 10/11，解压后双击 `GCM Next.exe`，**整个文件夹一起用**
- GCM 官方源需要私有签名服务，本版本只读本地旧库、无法下载；小幸条目只打开官方网页
- CT 条目的下载依赖 Yandex 网盘直链，接口限流时会提示稍后重试
- 仅供单机游戏使用，详见 README 的免责声明

### 校验
- 体积：约 77 MB（onedir，含内置 7-Zip）
- 冒烟测试 54 项 + 真实下载安装的端到端测试均通过
```
